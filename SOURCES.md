일반 하네스 비교에서 참고한 계획 승인·작은 작업·선택 이유·검증 연결은 독자 지침으로 정리했으며 타 하네스 본문·설치기를 복제하지 않았다.
표현 프로필의 공식 규정·자체 제안·미확정은 skills/work-session/assets/presentation/SOURCES.md에 구분했다.
manifest의 source.commit은 원저작 버전이고 각 files 해시는 현재 수정 배포본의 SHA-256이다.

문서 Skill은 Addy 원문의 기존 관례 우선·이유/대안 보존·Prose Review 원칙을 재사용했다. 장문의 예시·새 ADR/릴리스 체계를 추가하지 않고 기존 정본과 한국어 CLI 가독성에 맞게 조정했다.

로컬 개선 후보의 기록 배치·방법 선택·검증 추론 참조와 실제 프로젝트 이해 구성은 독자 작성했다. 비교한 작업 지침의 설계 개념을 기존 정본/승인 흐름에 맞게 조정했으며, 세부 비교 출처와 채택 이유는 배포본 밖의 검토 보고서에 보존한다. 추가 실행기·외부 킷의 구현 파일은 포함하지 않는다. 기존 보조 Skill의 원저작 고지와 라이선스는 그대로 유지한다.

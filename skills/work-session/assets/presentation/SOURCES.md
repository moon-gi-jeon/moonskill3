## 색상 표기

원문의 Red·Orange·Navy·Teal·White·Black HEX를 참고했다. Orange는 `##F47725`와 RGB `255 / 122 / 0`으로 표기되어 있다. 중복된 # 표시는 하나로 정리한 `#F47725`를 선택했고, 계산상 RGB는 `244 / 119 / 37`이다. 두 RGB 값을 같다고 처리하지 않는다.

## 파일과 적용 범위

색상 값·직접 작성한 구성 제안·공식 출처 링크를 제공한다. 로고 그림·회사 글꼴·페이지 화면·타 킷 디자인 파일은 포함하지 않았다. 해당 자산의 재배포 허용을 확인했다는 주장은 하지 않는다. 로고가 별도로 필요하면 실제 공식 자산과 적용 규정을 확인한다.

범용 작업 흐름과 표현 프로필은 분리한다. 과제 지정 형식·데이터 의미·접근성·명시적 사용자 방향을 우선한다. 색상 때문에 CSV/JSON 스키마를 바꾸거나 없는 브랜드·서비스 소속을 표시하지 않는다.

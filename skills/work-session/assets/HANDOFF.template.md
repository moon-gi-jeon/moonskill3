# 인계 — 실제 전환할 때만 사용

기존 PLAN의 인계 절이 충분하면 그곳을 사용한다. 별도 HANDOFF가 유용할 때만 이 양식을 쓰고 PLAN에 경로를 둔다. PLAN·DECISIONS·REVIEW·실제 파일이 정본이며, 같은 요구·진행표를 두 곳에서 유지하지 않는다. 아래 항목은 실제 확인한 값만 적는다.

- 현재 단계와 AI 사용 가능 여부 / 실제 확인 시점 또는 미확인:
- 목표·승인 범위와 근거: PLAN의 요구·승인 위치:
- 정본 경로: PLAN / DECISIONS / REVIEW / 주요 입력·출력·코드:
- 실제 저장 상태: 중요 변경·미저장 여부·사용 가능한 경우에만 commit/hash:
- 마지막 유효 검사: 명령 또는 관찰 / 입력 / 기대·실제 / exit / 대상 버전·근거 경로:
- 남은 필수 요구·장애·가정·사람 확인 / 관련 요구 ID:
- 다음 한 행동과 완료 확인 / 대기 중인 검토가 있다면 상태:
- 새 세션에 필요한 실제 권한·규정·중단 조건:

재개 시 요약을 사실로 간주하지 말고 현재 파일·입력·근거를 대조한다. 바뀌었거나 확인할 수 없는 관련 근거만 다시 검사한다. 비밀값·대화 전문·금지된 단계의 답안은 기록하지 않는다.

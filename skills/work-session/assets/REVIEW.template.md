# REVIEW

첫 관련 검증부터 실제 상세 근거를 기록한다. 비해당 사실을 만들어 채우지 않는다. PLAN은 ID·짧은 결과·상태·여기 위치만 연결한다.

<a id="v01"></a>
## V01 — 실제 검증 대상

- 관련 요구·후보·파일/버전·입력 범위:
- 상태:
- 성공/기대값과 출처:
- 방법·왜 타당한가·기대값 독립성:
- 실제 실행/허용 조작·관측 결과·근거 위치:
- 확인한 범위·미확인·한계·영향:
- 사용한 대안·대리지표·가정과 오해 위험(해당 시):
- 변경 시 재검증 조건·이전 근거 대체 관계:

결과와 기대를 같은 구현에서 만든 경우 이를 독립 검증으로 표시하지 않는다. 실행하지 않은 검사는 NOT_RUN, 사람이 확인해야 하는 항목은 HUMAN_CHECK, 변경으로 효력이 없어진 근거는 STALE로 구별한다.
